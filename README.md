# 📊 Business Intelligence AI Agent

A smart Streamlit-based Business Intelligence Assistant that reads multiple CSV datasets (Deals + Work Orders), cleans messy data, and answers founder-level business questions using natural language queries.

---

## 🚀 Features

* 📁 Auto-detects CSV files from project folder
* 🧹 Cleans inconsistent dataset column names and missing values
* 💰 Calculates Total Revenue
* 📊 Finds Average Deal Size
* 🏆 Calculates Win Rate
* 📈 Shows Pipeline Status
* 📋 Shows Work Order Status
* 🏢 Sector-wise Revenue Analysis
* 👤 Top Owner / Salesperson Performance
* 📌 Executive Dashboard with KPIs
* 🧠 Auto Insights Summary
* 🌐 Deployed using Streamlit Cloud


